Veelgestelde Vragen

Alles wat je moet weten over de Minecraft server & stream

Hoe kan ik meedoen op de Minecraft server?
Start Minecraft Java Edition en voeg het serveradres play.florisn.nl toe in je serverlijst!
Kan ik ook meedoen via Minecraft Bedrock (Console/Telefoon)?
Op dit moment is de server ingesteld voor Java Edition. Bekijk onze Discord voor updates rondom Bedrock ondersteuning!
Hoe werkt de Simple Voice Chat mod?
Download en installeer de Simple Voice Chat mod in je Minecraft client om in-game direct te praten met spelers die dichtbij je staan.
Waar kan ik mijn spelerstatistieken bekijken?
Je kunt je in-game speeltijd, statistieken en prestaties inzien op de Minecraft SMP Statistieken pagina.
